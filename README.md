# NBI Clearance Help — Complete Static Website

Domain: `nbiclearancehelp.com`
Target country: Philippines
Build type: clean static HTML/CSS/JS, ready for Cloudflare Pages.

## Deploy to Cloudflare Pages

This project has no build dependencies. Upload the folder contents as a static site. If using Git integration, set:
- Build command: leave blank
- Output directory: `/` (repository root)

## Important files
- `index.html` — long-form homepage
- page folders — SEO guides and trust pages
- `assets/images/` — original guide diagrams and illustrations
- `sitemap.xml` — all indexable pages
- `robots.txt`
- `_headers` — basic security/cache headers for Cloudflare Pages
- `_redirects` — www → non-www redirect

## Editorial notes
- Independent site; not affiliated with NBI or the Philippine Government.
- Core factual content was checked against official NBI sources on 14 September 2026.
- No city-specific SEO doorway pages were created. Branch content is kept in one Philippines-wide hub.
- No passwords, OTPs, ID scans or sensitive identity data should be collected.
